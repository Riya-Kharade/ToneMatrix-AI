# 🎭 ToneMatrix AI – Marathi Sentiment & Sarcasm Analysis

**ToneMatrix AI** is an AI-powered Marathi Natural Language Processing (NLP) platform designed to understand emotions and detect sarcasm in Marathi text. It combines multilingual Transformer models with an interactive web interface to make Marathi text analysis easier and more effective.

## 🌟 Project Overview

Understanding human emotions in regional languages is a challenging task, especially when sentences contain sarcasm, context-dependent meanings, and informal expressions.

ToneMatrix AI aims to address this challenge through two major NLP tasks:

- **Sentiment Analysis:** Identifies whether Marathi text expresses Positive, Negative, or Neutral sentiment.
- **Sarcasm Detection:** Determines whether a Marathi sentence is Sarcastic or Non-Sarcastic.

The platform also provides model comparison, dataset exploration, analytics, and research results.

## ✨ Features

- **Sentiment Analysis:** Classifies Marathi text into positive, negative, and neutral categories.
- **Sarcasm Analysis:** Detects sarcastic and non-sarcastic expressions.
- **Combined Analysis:** Performs sentiment and sarcasm analysis together.
- **Model Comparison:** Compares different NLP models.
- **Dataset Explorer:** Provides access to dataset information.
- **Analytics Dashboard:** Visualizes model performance and analysis results.
- **Research Results:** Displays experimental results.
- **Analysis History:** Maintains previous analysis records.
- **Interactive Dashboard:** Easy-to-use interface for Marathi NLP research.

## 🤖 NLP Models

The project explores multilingual Transformer-based models for Marathi language understanding.

| Model | Description |
|---|---|
| BERT | Bidirectional language representation model |
| mBERT | Multilingual BERT trained on multiple languages |
| RoBERTa | Optimized BERT-based language model |
| XLM-RoBERTa | Cross-lingual multilingual Transformer model |
| MuRIL | Multilingual model designed for Indian languages |
| DistilBERT | Lightweight and faster version of BERT |

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Riya-Kharade/ToneMatrix-AI.git
```

### 2. Navigate to the Project

```bash
cd ToneMatrix-AI
```

### 3. Start the Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Backend URL:

```text
http://127.0.0.1:8000
```

API Documentation:

```text
http://127.0.0.1:8000/docs
```

### 4. Start the Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal.
